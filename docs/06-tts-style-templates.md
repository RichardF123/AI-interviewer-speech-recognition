# TTS 风格模板

## 默认声音风格

默认面试官声音应当专业、温和、清晰、稳定，不过度情绪化。语速中等偏慢，关键问题前留短暂停顿，避免压迫感。

推荐默认参数：

- language：`zh-CN`
- voice：`zh-CN-XiaoxiaoNeural` 或同等级企业可商用中文普通话声音
- rate：`-5%` 到 `-10%`
- pitch：`0%`
- volume：`0%`
- pause：句间 200-500ms

## SSML 包装策略

- 先清洗文本，再包装 SSML。
- 用 `<break>` 控制自然停顿。
- 用 `<prosody>` 控制语速和音高。
- 不把原始 Markdown 直接送入 TTS。
- SSML 生成失败时降级为纯文本 TTS。

## 场景模板

### 开场白

```text
你好，我是今天的 AI 面试官。我们会围绕你的项目经历和岗位能力展开交流。准备好后，我们先从你的最近一个项目开始。
```

### 追问

```text
好的。这里我想再追问一下。你当时主要负责的是方案设计、模型实现，还是上线后的效果优化？
```

### 澄清

```text
我刚才可能没有听清。你可以再简单说一下这个项目里你负责的核心部分吗？
```

### 打断后恢复

```text
好的，我先听你补充。你可以继续说。
```

### 结束语

```text
好的，今天的语音面试到这里结束。感谢你的时间，后续结果会由招聘团队统一通知。
```

## 中文普通话默认 SSML 示例

```xml
<speak version="1.0" xml:lang="zh-CN">
  <voice name="zh-CN-XiaoxiaoNeural">
    <prosody rate="-8%" pitch="0%">
      好的。<break time="300ms"/>
      那我想继续追问一下排序模块。
      <break time="300ms"/>
      你当时主要优化的是特征、模型结构，还是线上策略？
    </prosody>
  </voice>
</speak>
```

## 英文或双语扩展

- 根据 session `language` 选择中文、英文或双语 voice。
- 中英混排时先规范缩写读法，例如 API、SQL、KPI。
- 双语面试中不要频繁切换语言，除非候选人主动使用英文回答或岗位要求英文能力。

## 文本清洗规则

- 删除 Markdown 标记：标题、列表符号、加粗、链接语法。
- 删除代码块和不可朗读的 JSON 片段。
- 把长句切成 15-30 个汉字左右的短句。
- 规范数字、百分比、金额、英文缩写。
- 删除括号中的系统提示，例如“（停顿）”“[笑]”。
- 避免连续多个问题。

## OpenAI TTS 备选说明

OpenAI TTS 可作为备选 provider，适合统一 OpenAI 技术栈或需要快速集成的场景。使用时仍需保留 `SpeechStyleFormatter`，通过文本前处理控制语气、停顿和可朗读性。

## 非商用验证方案说明

Edge TTS、ChatTTS、Bark 等可以用于本地研究或非商用验证，但授权、服务条款、稳定性或商用责任不明确，不能作为商业上线默认方案。CosyVoice、Fish Speech 等开源或开放模型用于商用前也必须完成 license、声音授权和部署成本评估。
